\section{Conclusion}
\label{sec:conclusion}

SDD makes public semantic regions the unit of private knowledge exchange.
One released regional target supervises many proxy examples; fixed $K$
controls the $KC$-coordinate report and whole-client sensitivity
$\sqrt{2K}$. With frozen public representations, actual 10k strongly
heterogeneous CIFAR-10 clients and $\varepsilon=0.1$, the fixed configuration
without public task labels reaches $84.2\%$ using 100 coordinates, gaining
14.4 points over per-example transfer with $200\times$ fewer report
coordinates. Separate matched structure controls identify the value of
semantic geometry, and natural-author results characterize regional
supervision allocations. Regional target reuse extends client-sourced
supervision through a compact, protected knowledge-transfer interface.
