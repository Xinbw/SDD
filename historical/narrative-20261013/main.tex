\title[Semantic-DP Distillation]{Semantic-DP Distillation: Learning through Semantic Clusters
at Small Privacy Budgets}

\author{Anonymous Author(s)}

\begin{abstract}
Community-content learning needs shared supervision when labels remain with
clients and public proxies are unlabelled. Joint per-example vote reports make
whole-client sensitivity grow with proxy size, although related examples can
share supervision. Semantic-DP Distillation (SDD) makes public semantic regions
the unit of private knowledge exchange: each client casts one class vote per
region, and the released regional target supervises every proxy example in
that region. For $K$ fixed public regions, the report contains $KC$ coordinates
with tight replace-one sensitivity $\sqrt{2K}$. Established distributed integer
noise and adaptive accounting provide whole-run client privacy under protected
aggregation. On frozen public representations with $10^4$ strongly
heterogeneous CIFAR-10 clients, a fixed configuration using no public task
labels achieves $84.2\%$ accuracy over five seeds at $\varepsilon=0.1$ and
$\delta=10^{-5}$, versus $42.4\%$ for independent learning and $69.7\%$ for
per-example DP-FedCT. The 100-coordinate report gains $14.4$ percentage points
with $200\times$ fewer coordinates. Separate public-configured controls yield
$85.0\%$ for semantic regions versus $48.9\%$ for size-matched random regions.
With public configuration selection, a ten-seed Usenet study of 3000 distinct
authors reaches $26.3\%$ balanced accuracy at $\varepsilon=1$, gaining $5.1$
points over per-example transfer using 30 rather than 9000 coordinates.
Semantic reuse extends the supervision supplied by each bounded private report.
\end{abstract}
