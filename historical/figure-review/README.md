# 论文的三张证据图

运行 `python plot_candidates.py` 会重建 `figure-review/` 中的 PDF／PNG 及 `paper/figures/` 中的矢量 PDF。

1. **主曲线**：完整展示 7 个预算 × 4 个数据设置，直接标注 +14.2／+45.1 个百分点及同目标预算优势。均值和标准差直接从冻结结果读取。
2. **机制图**：队列噪声标定的效用转折对应 margin 规划估计；DP-FedAvg 的同一 schedule 准确率与噪声比成对展示，另一 schedule 用独立标记。
3. **设计图**：硬标签 CE／软标签 KL 放在首位，其后展示粒度与报告载荷、固定总预算下的轮次分配。柱状图从零起，单 seed 和三 seed 口径在论文 caption 中明确。

主结果均为 3 seeds，阴影是 seed 标准差。T 扫描的三 seed 点有误差棒：T=3，以及 CIFAR-10 T=5；其余诊断点为单 seed。所有图保留相应冻结测点。MIA 的精确数值保留为表。

主曲线将本文评估的 PATE 实现统一标为 PATE-DI，会计协议见论文 §5.1。主结果以 100 个训练客户端估计共识、按部署 cohort 10^4 标定噪声；队列扫描改变该噪声标定。图中不加入无隐私结果或旧机制结果。
