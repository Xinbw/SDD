\title[Semantic-DP Distillation]{Semantic-DP Distillation: Choosing the Granularity
of Client-Private Supervision}

\author{Anonymous Author(s)}

\begin{abstract}
Strong public features leave a private design question: at what granularity
should clients release task supervision? Per-example votes spend sensitivity
on every public query, while a regional target reuses supervision across related
examples. Semantic-DP Distillation (SDD) releases one bounded class vote per
public semantic region, yielding $KC$ coordinates and tight replace-one
whole-client sensitivity $\sqrt{2K}$. We characterize regional target quality
through an exact purity--decoding decomposition and a margin-dependent noise
bound, and use a public-only approximation to choose release resolution.
At taxonomy resolution, weighted matching provides an alternative decoder
that preserves class coverage without an additional privacy release.
On frozen public representations with $10^4$ strongly heterogeneous CIFAR-10
clients, matching reaches $86.3\%$ accuracy at $\varepsilon=0.1$,
$\delta=10^{-5}$ without public task labels, confirmed by an independent
five-seed group, using $200\times$ fewer report coordinates than per-example
transfer. Natural-writer and natural-author studies characterize how public
geometry and participation govern the choice of release. Compact head averaging
supplies higher accuracy when its parameter release is supported by the cohort
and budget. SDD makes semantic reuse a measurable resource for private supervision.
\end{abstract}
